# FITLOT

**FITLOT** is a responsive fitness planning web application built with modern React and Next.js technologies. It allows users to create their daily workout plan, save exercises for later, view workout summaries, and sort their selected exercises.

## Live Features

- **Select Today's Plan** — Add exercises to your daily workout plan.
- **Save Plan for Later** — Save exercises that you want to use later.
- **Total Summary** — View the total workout summary based on your selected exercises.
- **Sort Feature** — Sort your workout plan based on available options.
- **Mobile Responsive** — Fully responsive design for mobile, tablet, and desktop devices.

## Technologies Used

- **React**
- **Next.js**
- **TypeScript**
- **Tailwind CSS**
- **DaisyUI**

## ✨ Key Features

### Today's Plan

Users can select exercises and add them to their current workout plan. The selected exercises are displayed in a dedicated plan section.

### Save for Later

Users can save exercises for later instead of adding them directly to today's workout plan.

### Workout Summary

FITLOT provides a visible summary of the selected workout, helping users quickly understand their overall plan.

### Sort

Users can sort their selected workout exercises according to the available sorting options.

### Responsive Design

The application is designed to work smoothly across different screen sizes, including:

- 📱 Mobile
- 💻 Desktop
- 📱 Tablet

## 🧩 Challenges

### 1. Implementing the Sort Feature

One of the main challenges was implementing the sorting functionality while keeping the workout data and UI synchronized.

### 2. Managing Context

Managing shared workout data across multiple components was another challenge. React Context was used to share and update workout-related state without unnecessarily passing props through multiple component levels.
